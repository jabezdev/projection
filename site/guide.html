Guide

Setting up PALTO

From the installer to a full Sunday. Each part stands on its own; skip what your church does not use.

Install

  1. Download the Windows installer on the church computer.
  2. Run it. Windows may say it protected your PC from an unknown publisher: choose More info, then Run anyway.
  3. Start PALTO from the Start menu.

The warning appears because the installer is not signed with a paid certificate. Every download comes from the project's GitHub releases, and updates inside PALTO are signed and checked before they install.

On the first start of each version, PALTO checks the computer: displays, audio, graphics speed, the video decoder, network and firewall. It writes the result to logs\system-check.log in PALTO's data folder (%APPDATA%\com.magi.projection). To run it again, start PALTO.exe --system-check.

Screens

Connect the projector, and the stage screen if you have one, before starting PALTO. Set Windows to Extend these displays.

  1. Open Settings at the bottom left of PALTO.
  2. On Projection, pick the projector's display and turn it on. Choose the font, size and position of the lyrics.
  3. On Confidence, pick the stage screen. Singers see the current slide and the next one.
  4. On Logo & backgrounds, set the logo shown between parts and the default background behind lyrics.

If a display is unplugged during a service, PALTO keeps running; pick the display again in Settings if the output does not come back on its own.

Songs

A song is a set of parts (verses, choruses, a bridge) and a usual order. Each part has a colour, so the order reads at a glance: V1 C V2 C B C.

  • Add a song in the Library: paste the lyrics. Lines like Verse 1, [Chorus] or Bridge: start a new part. A blank line inside a part starts a new slide.
  • Import OpenLyrics files (.xml) with their credits, CCLI number and copyright.
  • Change one Sunday only: in a service, drop or repeat a part, or change its words. The library song stays as it was.
  • Past services keep the words they used, even after the song is fixed in the library.

Services and templates

A service is a dated order of items: songs, text, scripture, images, videos, PDF slides and screen captures. Section headings group them.

A template is your usual order. PALTO starts with a Sunday template: Welcoming, Countdown, Praise & Worship, Tithes and Offering, Special Number, Message, Special Program and Closing. The two Special parts are optional.

  1. Choose New service… from the service menu, pick a template and tick this week's parts. Optional parts start unticked.
  2. Fold sections you are not working on. Remove a section with or without its items, or clear every empty one at once.
  3. Use Add part… to bring back a part you left out. It lands in its usual place.
  4. To keep the countdown video or the offering slide in every service, build a service with them and choose Save as template…. Songs are left out unless you ask.

Running a service

Click a slide to show it. From then on, the keyboard is enough:

KeyDoes
→ Space Page DownNext slide, then the next item
← Page UpPrevious slide
↓ ↑Next or previous item
B or .Black screen
CClear the words, keep the background
LShow the logo
EscBack to live
PPlay or pause the video or audio

Presentation clickers send Page Up and Page Down, so they work as they are. Change any key, or add MIDI notes, in Settings → Controls.

Phone remote

Any phone on the same Wi-Fi can run the service: see what is on screen and what comes next, jump to any song or slide, play and pause videos, and switch to black or logo.

  1. In PALTO, open Settings → Remote and turn on Allow phones and other computers on this network.
  2. On the phone, open http://palto.local:8080, or scan the QR code in that same settings page.
  3. Choose Pair a device in PALTO and type the 6-digit code on the phone. Each phone pairs once.
  4. Add the page to the home screen to open it like an app.

If the phone cannot connect, check that Windows treats the network as Private (Settings → Network → Properties), and use the number address PALTO shows instead of palto.local. Remove a lost phone from the same page.

Team library

The team library is a web app where song leaders add songs, set arrangements and plan services, and singers read the lyrics. PALTO keeps its own copy and syncs with it.

Roles

RoleCan
AdminEverything, and choose everyone's role. The first account is the admin.
LeaderEdit songs and plan services
LibrarianEdit songs
OperatorPlan services and pair projection computers
SingerRead lyrics and see what is on screen now

Connect PALTO

  1. On the web, open Team → Projection computers and create a pairing code. It shows the team address too.
  2. In PALTO, open Settings → Cloud sync, enter the address and the code, and name the computer.
  3. PALTO sends what it has and fetches the team's songs, services, templates and media (up to 100 MB per file).

While PALTO runs a service live, the web shows it as live and nobody can change it there. If the same thing was changed in both places, PALTO lists it under Needs attention with both versions side by side; the service carries on meanwhile. Work offline stops syncing completely.

Host one for your church

The library runs on Convex and any static host. The README has the steps: create a Convex project and a Cloudflare Pages project, add three keys to the repository, and run the deploy workflow.

OBS livestream

The PALTO plugin for OBS adds three text sources: PALTO Lyrics, PALTO Song Info (title and credits) and PALTO Section (for example "Verse 1"). OBS draws the text, so the font, colour and outline match your stream.

  1. In PALTO, turn on Settings → Remote → Share lyrics with OBS.
  2. On the OBS computer, run the plugin installer. It needs OBS 30 or newer on Windows.
  3. In OBS, add a PALTO source. It finds PALTO on the network; pick the computer, or type its address.

The plugin only reads what is on screen. It needs no pairing and cannot change anything in PALTO.

Stream Deck and Companion

PALTO accepts OSC messages, so Bitfocus Companion can drive it from a Stream Deck.

  1. In PALTO, open Settings → Remote and turn on Accept OSC messages. The port is 9000 unless you change it.
  2. If Companion runs on another computer, turn on network access and list that computer's IP address under OSC.
  3. In Companion, add a Generic OSC connection to the PALTO computer and port, then give each button an OSC send action with one of these addresses:
AddressDoes
/palto/next · /palto/previousNext or previous slide
/palto/next_item · /palto/previous_itemNext or previous item
/palto/live · /palto/black · /palto/clear · /palto/logoWhat the projector shows
/palto/play_pause · /palto/stopVideo and audio

A message with the value 0 is treated as a button release and ignored, so a button that sends on press and release still acts once.

Updates

Settings → System shows the version and checks for updates. An update installs only when you choose Install and restart, and never while the outputs are showing. If a new version causes trouble, the same page can reinstall an earlier one.

When something is wrong

  • A video stutters: run the system check and look at the video decoder line. A GTX 1050 Ti or newer handles 1080p easily; integrated graphics prefer H.264 files.
  • The projector shows the wrong screen: pick it again in Settings → Projection. Windows sometimes renumbers displays after a restart.
  • Phones cannot connect: the network must be Private in Windows, and the phone on the same Wi-Fi, not a guest network.
  • Sync says it can't reach the team library: everything keeps working. Changes go up when the connection is back.
  • Anything else: PALTO's logs are in %APPDATA%\com.magi.projection\logs. Attach them to a GitHub issue.
